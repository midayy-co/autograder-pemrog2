# Autograder Konverter Kurs

Autograder mini project Pertemuan 3 (Praktikum Pemrograman Komputer 2): Konverter Kurs.

- **Cek mandiri (praktikan):** tempel `kurs.py` dan `main.py`, klik Nilai, nilai dan rinciannya langsung keluar.
- **Rekap nilai (asisten):** masukkan semua zip `[NPM]_[Nama]_P3.zip`, lalu unduh CSV.

Semua dijalankan di browser dengan [Pyodide](https://pyodide.org) 0.26.4; kode praktikan tidak dikirim ke server mana pun.
`grader.py` juga bisa dijalankan langsung: `python grader.py folder_berisi_kurs_dan_main`.
